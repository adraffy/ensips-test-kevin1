# ENSIP-1: ENS Root Registry

## Abstract

This ENSIP defines the root ENS registry contract, which stores ownership and resolver information for all ENS domains.

## Motivation

A decentralized naming system requires a root registry that maps human-readable names to machine-readable addresses.

## Specification

The ENS registry is a single contract that maintains a mapping from domain name hashes (namehashes) to owner addresses and resolver contract addresses.

### Namehash Algorithm

Domain names are converted to a fixed-length hash using the namehash algorithm, which recursively hashes labels from right to left.

## Rationale

A single registry contract provides a simple and efficient lookup mechanism for all ENS names.
