# ENSIP-3: Reverse Resolution

## Abstract

This ENSIP defines a mechanism for reverse resolution, allowing Ethereum addresses to be mapped back to ENS names.

## Motivation

Forward resolution (name to address) is only half of the naming problem. Applications also need to display human-readable names for addresses they encounter.

## Specification

Reverse resolution uses a special domain under `addr.reverse`. For any Ethereum address, its reverse record is stored at `<address>.addr.reverse`.

### Claiming a Reverse Record

The owner of an address can claim the corresponding reverse node by calling the reverse registrar contract.

## Rationale

Using a dedicated namespace under the ENS hierarchy for reverse records keeps the system consistent and allows reverse resolution to use the same resolver infrastructure.
